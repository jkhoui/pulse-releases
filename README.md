# Pulse releases

Pulse is a Windows desktop dashboard for PC monitoring and optional server, smart home, camera, local AI, and VNC integrations.

## Current release status

Pulse 2.1.0 is an **unsigned Windows x64 prerelease**. It is not yet ready for Microsoft Store certification. Trusted code signing and installation/uninstall validation remain outstanding.

Download the installer and SHA256SUMS.txt from the Releases section. Do not bypass Windows security warnings to install this preview.

The installer bundles the local Node.js runtime. Pulse opens in an Edge app window or a modern browser and uses localhost port 3001. Optional integrations require your own compatible services and credentials.

This repository distributes release artifacts. It does not contain personal connection settings or credentials.
