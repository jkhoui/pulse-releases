Pulse Command Center Privacy Policy

Effective date: October 2, 2026. Publisher: Ktron ai.

This policy describes the Pulse Command Center Windows development-preview package prepared for the Microsoft Store (version 2.2.2.0). The app is designed to show information on your PC and connect to services that you choose. It does not include a hosted monitoring service.

Information handled by Pulse

  • PC and network status: Pulse reads hardware status, the PC host name, local network interfaces, and the state of targets you configure so it can display local dashboards. This information stays on your PC; this package does not send it to Ktron ai.
  • Connection settings and credentials: If you connect Proxmox, TrueNAS, Home Assistant, a sensor exporter, or another supported service, Pulse stores the server addresses and settings you enter in files under your Windows user profile, by default %LOCALAPPDATA%\PulseCommandCenter. Credentials, including API tokens, are used from your PC to connect to those services. Pulse does not send your integration credentials to Ktron ai.
  • Workspace, trial, and license state: Pulse stores configured targets, local trial timestamps, and a random installation identifier in the same local data directory. The identifier is generated for licensing, but this package does not send it to Ktron ai because production billing is not configured.
  • Local AI: If you use the optional AI view, Pulse sends prompts to the Ollama endpoint configured for the app (by default, Ollama on the same PC). The endpoint operator may process prompts you send. Prompts are not sent to Ktron ai by Pulse.
  • Connected services: Pulse sends requests and the relevant credentials from your PC to the server addresses you configure. Those service operators handle the information under their own privacy practices. Ring and Blink connections use the Home Assistant integrations you configure; they are not operated by Ktron ai.

The app code in this package does not include advertising or analytics. It does not transmit your dashboard contents, local network status, AI prompts, or integration settings to Ktron ai. Windows and Microsoft Store may process information under Microsoft's Privacy Statement, including to operate Store downloads or transactions.

Storage, security, and deletion

Pulse stores its settings and local state under your Windows user profile. Pulse does not encrypt the connection settings file itself; protect your Windows account and device, use read-only credentials when available, and do not share the Pulse data folder.

To remove Pulse's local data, exit Pulse and delete %LOCALAPPDATA%\PulseCommandCenter. This removes saved connections, targets, trial state, and local licensing files. Uninstalling Pulse may not remove this folder. Deleting Pulse data does not delete information stored by a server you connected to; contact that service's operator for those records.

The current package has no production billing configuration and sends no Pulse account, installation, or subscription record to Ktron ai. Ktron ai therefore has no remote Pulse profile from this package to access, correct, or delete. If a future release adds publisher-hosted billing or account services, this policy will be updated with the information involved, providers, retention, and contact method before that release is made available.

Other providers

Microsoft handles Microsoft Store account and transaction data under Microsoft's own privacy practices. The services you connect to, and any Ollama endpoint you choose, receive information necessary for the requests you make to them. The page hosting this policy is delivered by GitHub Pages; GitHub may process your IP address and browser/request information to host and secure the site under GitHub's Privacy Statement.

Questions

For general questions about Pulse or this policy, use the Pulse Releases issue tracker. Issues are public. Do not post personal information, credentials, private network addresses, device identifiers, or subscription details there.

For information stored by Microsoft or a service you connect to, contact that provider directly. You can view, change, or remove Pulse's local settings on your PC as described above. Pulse does not send the data described in this policy to Ktron ai in this development-preview package.

Changes

This policy will be updated if Pulse's data practices change. The effective date at the top identifies the latest revision.
